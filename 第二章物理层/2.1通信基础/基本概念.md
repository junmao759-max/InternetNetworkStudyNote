###### 2.1 通信基础

###### 2.1.1 基本概念

1. **数据、信号、码元**
    
    - 数据：传送信息的实体，分两类
        
        ①模拟数据：取值连续（声音、图像）；②数字数据：取值离散（文字、数字）
    - 信号：数据传输的电气 / 电磁表现，对应分模拟信号、数字信号
    - 码元：固定时长的信号波形，时长 = 码元宽度 / 信号周期；k 进制码元 1 个周期携带 \(\log_2k\) bit 信息量
        
        例：4 进制码元 = 2bit，2 进制码元 = 1bit
    
2. **单向通信系统模型**
    
    信源 → 变换器 → 信道 → 反变换器 → 信宿；噪声源作用于信道
    
    - 信源：产生、发送数据；信宿：接收数据
    - 信道：信号传输介质，双向线路含发送、接收两条信道
    
3. **信道分类**
    
    1）按信号形式：模拟信道（传模拟信号）、数字信道（传数字信号）
    
    2）按传输介质：有线信道、无线信道
4. **信号传输分类**
    
    - 基带传输：直接传输未调制原始基带信号
    - 宽带传输：基带信号调制后频分复用传输
    
5. **数据传输方式**
    
    - 串行传输：比特逐位依次传，远距离网络使用
    - 并行传输：多比特多通道同步传，计算机内部（CPU - 内存）使用
    
6. **通信交互方式**
    
    表格
    
    |类型|特点|信道需求|例子|
    |---|---|---|---|
    |单向通信|仅单一方向传输，无反向交互|1 条信道|广播、电视|
    |半双工通信|双方均可收发，但**不能同时**收发|2 条单向信道|对讲机|
    |全双工通信|双方可同时收发信息|2 条单向信道|手机通话|

###### 2.2 速率、波特与带宽

###### 1. 两个速率定义

1）**码元速率（波特率 Baud）**

每秒传输码元个数；仅描述波形数量，和码元进制无关。

2）**信息传输速率（比特率 b/s）**

每秒传输比特数量，描述数据量。

###### 2. 换算关系

单个码元携带 \(n=\log_2k\) bit（k 为进制）

比特率 = 波特率 × 单码元比特数，即：\(R_b=R_s \times \log_2k\)

###### 3. 带宽

1）模拟系统：频率带宽，最高频 - 最低频，单位 Hz

2）计算机网络：最高数据传输速率，单位 b/s（描述线路数据承载能力）

###### 补充核心考点笔记

1. 1 个 k 进制码元携带信息量公式：\(\log_2k\) bit
2. 串行 / 并行传输适用场景区分
3. 三种通信交互方式的信道数量差异
4. 波特率≠比特率，进制决定两者倍数关系
5. 基带 / 宽带传输的核心区别：是否经过调制
6. 信道两大划分维度：传输信号类型、物理介质
