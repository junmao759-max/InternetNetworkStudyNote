## 5.3.2 TCP 报文段

1. 整体：TCP 报文段 = **TCP 首部 + 数据**；作为 IP 数据报的数据部分传输。
2. **首部**

- 固定部分：**20 字节**；选项部分最多 40 字节；**TCP 首部范围：20~60B，4B 整数倍**。
- 数据偏移：4bit，单位 4 字节，表示 TCP 首部长度；最大值 15 → 15×4 = **60 字节**。

### TCP 首部字段（必考）

表格

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 源端口、目的端口 | 各 2B | 复用分用 |
| **序号 seq** | 4B | 本报文段发送数据**第一个字节的序号**；整个字节流每个字节都有序号。SYN/FIN 报文即使不带数据，**也要消耗一个序号**。 |
| **确认号 ack** | 4B | 期望收到对方下一个报文段第一个字节序号；ack=N，代表**N‑1 之前全部收到**；只有`ACK=1`确认号才有效。 |
| 数据偏移 | 4bit | TCP 首部长度，单位 4 字节 |
| 保留 | 6bit | 置 0 |
| **URG** | 1bit | 紧急位。`URG=1`，紧急数据；配合**紧急指针**；紧急数据插入报文最前面，不等待缓存满。 |
| **ACK** | 1bit | 确认位。连接建立后**所有报文 ACK 必须置 1**。 |
| **PSH** | 1bit | 推送。接收方收到立刻上交应用层，不要缓存。 |
| **RST** | 1bit | 复位。连接严重出错，释放连接，重建连接；拒绝非法报文。 |
| **SYN** | 1bit | 同步。连接建立。`SYN=1,ACK=0`连接请求；`SYN=1,ACK=1`连接响应。消耗序号。 |
| **FIN** | 1bit | 终止。释放连接，`FIN=1`，发送方不再发数据，消耗序号。 |
| **窗口 rwnd** | 2B | 接收窗口，单位字节；从确认号开始，本方接收缓存还能接收多少字节；**流量控制核心**。 |
| 检验和 | 2B | 检验**TCP 首部 + 数据**；计算检验和需要**12 字节伪首部**，伪首部协议号改为 6（TCP）。 |
| 紧急指针 | 2B | URG=1 有效，指出紧急数据字节数。 |
| 选项 | 最多 40B | MSS 最大报文段长度、窗口扩大、时间戳等。 |

> 
> MSS：TCP 报文段**数据部分最大长度**，不含 TCP 首部。
