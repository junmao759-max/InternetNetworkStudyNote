
## 5.2 UDP 首部格式（8 字节，4 个字段，每个字段 2B）

表格

| 字段 | 说明 |
| --- | --- |
| 源端口号 | 需要回信时填写；不需要回信可以填 0 |
| 目的端口号 | 终点交付报文必须使用 |
| UDP 长度 | UDP 数据报总长度（首部 + 数据）；**最小值 8B（只有首部无数据）** |
| UDP 检验和 | 检测 UDP 数据报是否出错，出错丢弃；**可选，填 0 代表不计算检验和** |

> 
> 考点：接收 UDP 报文，目的端口不存在 → **丢弃报文，ICMP 发送端口不可达差错报告报文**。

### UDP 分用

根据**目的端口号**，把 UDP 数据报上交对应应用进程。

1. **伪首部（12 字节）**

- 仅用于计算检验和，**既不向下交给 IP 层，也不上交应用层**，临时使用。
- 伪首部字段：源 IP 地址 (4B)、目的 IP 地址 (4B)、0 (1B)、UDP 协议号 (1B)、UDP 长度 (2B)。

1. IP 检验和 vs UDP 检验和

- IP 检验和：**只检验 IP 首部**
- UDP 检验和：检验 **UDP 首部 + UDP 数据部分**

1. 检验和计算步骤（二进制反码求和）
**发送方：**
1）检验和字段置 0；
2）伪首部 + UDP 报文看成若干 16bit 字；
3）若数据字节数为奇数，末尾填充 1 个全 0 字节（填充字节**不发送**）；
4）二进制反码求和；
5）将结果反码写入检验和字段，发送。

**接收方：**
1）伪首部 + UDP 全部内容做二进制反码求和；
2）结果全 1：无差错；结果不全 1：出错。
