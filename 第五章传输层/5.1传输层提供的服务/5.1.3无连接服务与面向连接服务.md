## 5.1.3 无连接服务 (UDP) 与面向连接服务 (TCP)

### TCP（面向连接）

1. **面向连接**：传输数据前必须建立连接；传输完毕释放连接。
2. **可靠传输**：确认、重传、流量控制、拥塞控制。
3. **全双工通信**。
4. 不支持广播、多播。
5. 开销大，报文首部大，占用 CPU 资源。
6. 适用场景：对可靠性要求高：FTP、HTTP、TELNET、SMTP。

### UDP（无连接）

1. **无连接**：发送前不需要建立连接；收到报文不需要回确认。
2. **不可靠服务**：不保证交付、不保证有序。
3. 支持一对一、一对多、多对多（广播、多播）。
4. 开销小，速度快、实时性好。
5. 适用：DNS、TFTP、DHCP、SNMP、RTP。

### 易考辨析

1. IP 地址找**主机**；端口找**进程**；Socket=IP + 端口找**进程端点**。
2. TCP：面向连接、可靠；UDP：无连接、不可靠。
3. 熟知端口：0‑1023；登记端口：1024‑49151；临时端口：49152‑65535。
4. IP 数据报：路由器看完整首部；**UDP 报文封装在 IP 报内，路由器看不到 UDP 头部**。

### 简答题考点

1. 端口的作用？

> 
> IP 地址定位主机，端口号定位主机内部的应用进程，传输层使用端口完成复用与分用。

1. Socket 套接字是什么？

> 
> IP 地址 + 端口号，唯一标识一个通信端点。
