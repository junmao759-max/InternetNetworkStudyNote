## 4.6.2 移动 IP 通信完整流程（高频简答）

前提：移动站 A 永久地址：`131.8.6.7/16`；归属网络：`131.8.0.0/16`；漫游到被访网络，拿到转交地址`15.5.6.7/8`；通信者 B 不知道 A 的位置。

1. 移动站 A 在归属网络：正常使用永久 IP 通信。
2. **A 漫游到外地网络**：向**外地代理登记**，获得转交地址；外地代理把转交地址上报给**归属代理**。
3. 通信者 B 向 A 的**永久地址**发送 IP 分组。
4. **归属代理截获数据包**，构建 IP 隧道：把原始整个 IP 分组**重新封装（外层新 IP 头）**，发给外地代理（转交地址）。
5. **外地代理拆封隧道报文**，取出内部原始 IP 分组，交付给移动站 A。

> 👉隧道：外层 IP 头目的 = 转交地址；内层完整保留原始 IP 数据包。

6. **A 回复 B**：源 IP 直接写自己**永久地址**，直接路由发给通信者 B，**不需要经过归属代理**（三角路由问题）。
7. A 回到归属网络：向归属代理注销转交地址，恢复正常通信。

### ⚠️三角路由（考点）

- 去程：B →归属代理隧道→A（绕归属代理）
- 回程：A 直接→B，不走归属代理 这种不对称路径叫**三角路由**，是移动 IP 的固有问题。

## 移动 IP4 个协议（选择填空）

1. 移动站到外地代理：**登记协议**
2. 外地代理→归属代理：**登记协议**
3. **归属代理封装协议**：隧道封装原始 IP 包
4. **外地代理拆封协议**：隧道解封装

## 必背易错考点

1. 转交地址只是**临时地址**，移动站对外身份依旧是永久归属 IP，上层 TCP 应用完全感知不到网络切换。
2. 隧道技术：归属代理做**封装**；外地代理做**拆封**。
3. 移动主机**发送报文时源地址仍然使用永久地址**，不用转交地址做源 IP。
4. DHCP 获取新 IP≠移动 IP：DHCP 会改变 IP，TCP 连接断开；**移动 IP 保持 IP 不变，维持 TCP 连接**。
5. 转交地址属于**被访网络**，不是归属网络。

## 简答模板

> 移动 IP 解决主机跨网络移动时 IP 地址改变导致 TCP 断开问题。移动站拥有永久归属 IP；漫游外地网络获得转交地址，上报归属代理；其他主机向永久地址发包；归属代理通过 IP 隧道封装转发至外地代理；外地代理解封装交给移动站；移动站回复报文直接路由回源主机。
