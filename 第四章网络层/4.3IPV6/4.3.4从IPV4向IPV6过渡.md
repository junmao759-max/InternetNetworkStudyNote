> 不能一夜切换，要求 IPv6 设备向后兼容，可收发、转发 IPv4 分组。

1. **双协议栈** 同一设备同时运行 IPv4、IPv6 两套协议栈，同时拥有两种 IP 地址。

- 和 IPv6 主机通信：使用 IPv6 地址
- 和 IPv4 主机通信：使用 IPv4 地址
- DNS 查询决定使用哪一套协议。

2. **隧道技术** IPv6 报文要穿越 IPv4 网络：**把整个 IPv6 数据报，当做 IPv4 的数据部分封装**；在 IPv4 网络里面 “隧道” 传输。出 IPv4 网络后解封装，交给 IPv6 协议。

## 高频考点背诵

1. IPv6 地址长度：**128 位**
2. IPv6 基本首部固定：**40 字节**
3. 路由器**不允许对 IPv6 报文分片，分片只能源主机完成**
4. 双冒号`::`在一个 IPv6 地址**最多只能出现 1 次**
5. 任播：发给一组节点，交付最近的一个节点；IPv4 没有任播
6. IPv6 取消首部校验和，减轻路由器负担；上层传输层完成校验
7. 解决 IPv4 耗尽：只有 IPv6 是根本方案，CIDR、NAT 只是缓解
8. IPv6 不需要 ARP，用 NDP 协议完成地址解析。
