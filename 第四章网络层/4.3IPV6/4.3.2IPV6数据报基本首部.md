> IPv6 报文 = **40B 基本首部 + 0 个或多个扩展首部 + 有效载荷**；扩展首部不属于基本首部。

### 对 IPv4 首部做的改动

- ✅取消**首部长度**：IPv6 基本首部固定 40 字节
- ✅取消**总长度**，改用**有效载荷长度**
- ✅取消服务类型；用**通信量类 + 流标号**实现服务质量
- ✅取消标识、标志、片偏移 → 分片交给**分片扩展首部**
- ✅TTL → **跳数限制**，功能完全一样，名字更贴切
- ✅取消协议字段 → **下一个首部**（指明后面是扩展首部还是上层协议）
- ✅取消首部检验和：传输层负责校验，路由器不用计算校验，提升转发速度
- ✅取消选项，全部改为**扩展首部**

### IPv6 基本首部字段（40 字节）

1. **版本 (4bit)**：IPv6 固定值 = **6**
2. **通信量类 (8bit)**：区分报文类别、优先级
3. **流标号 (20bit)**：源→目的的数据流，同一条流拥有相同流标号，路由器提供 QoS 保障
4. **有效载荷长度 (16bit)**：基本首部之后全部字节；最大65535字节
5. **下一个首部 (8bit)**：
    - 无扩展首部：等价 IPv4 的协议字段，指明上层协议 (TCP/UDP)
    - 存在扩展首部：指明**紧跟的扩展首部类型**
6. **跳数限制 (8bit)**：每经过一台路由器 - 1，到 0 丢弃报文（同 IPv4 的 TTL）
7. **源地址 128 位、目的地址 128 位**
