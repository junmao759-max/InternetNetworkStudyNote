1. CMP 属于**网络层协议**，封装在 IP 数据报的数据部分。
2. 两大类：**差错报告报文、询问报文**

###### （1）差错报告报文 5 类

① 终点不可达 ② 源点抑制（拥塞） ③ 时间超过：TTL 归零；分片重组超时 ④ 参数问题：IP 首部字段出错 ⑤ 改变路由（重定向）

> ❗**不发送 ICMP 差错报告的 4 种情况**

1. ICMP 差错报文本身；
2. IP 分片的**后续分片（非第一片）**；
3. 组播报文；
4. 特殊地址（回环、受限广播）。

#### （2）询问报文

- 回送请求 / 应答：`ping`命令
- 时间戳请求应答：测往返时延

3. 应用

- ping：ICMP 回送报文
- tracert (traceroute)：利用 ICMP**时间超过差错报文**追踪路由。

###### 网络层核心大题考点汇总

1. IP 分片计算：总长度、片偏移、MF 标志位计算。
2. 子网划分：定长 / VLSM，求子网网络地址、广播地址、可用主机范围。
3. CIDR、路由聚合、最长前缀匹配。
4. NAT 工作原理，转换表；区分普通路由器与 NAT 路由器。
5. ARP 四种场景，MAC 地址与 IP 地址变化。
6. DHCP 四次交互报文。
7. ICMP 报文类型，什么情况不产生 ICMP 差错。
