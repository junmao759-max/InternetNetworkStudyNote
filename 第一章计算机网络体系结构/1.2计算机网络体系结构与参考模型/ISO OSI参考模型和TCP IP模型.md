### 1. 物理层

- 传输单位：比特
- 功能：透明传输比特流；定义接口、电气信号规范
- 介质（网线 / 光纤）不属于协议内容

### 2. 数据链路层

- 传输单位：帧
- 核心功能：差错控制、流量控制；把物理无连接链路转为逻辑可靠链路
- 处理广播信道介质访问冲突

### 3. 网络层

- 传输单位：分组 / 数据报
- 核心：路由选择、拥塞控制、差错检测；跨网络转发分组
- 服务：无连接、不可靠（IP）

### 4. 传输层

- 单位：报文段 (TCP)、用户数据报 (UDP)
- 区分：链路层是**点到点**；传输层是**端到端（进程间通信）**
- 功能：端到端流量 / 差错控制、连接管理、分用复用
    
    - TCP：面向连接、可靠
    - UDP：无连接、尽力交付、不可靠
    

### 5. 会话层

建立 / 管理 / 同步主机进程会话，断点续传检查点机制

### 6. 表示层

数据格式转换、加密解密、压缩解压、编码兼容

### 7. 应用层

面向用户应用接口，各类应用协议（HTTP/FTP/DNS/SMTP）

## 二、TCP/IP 四层模型（工业事实标准）

1. **网络接口层**：合并 OSI 物理 + 数据链路层，传输 IP 分组
2. **网际层（互联网层）**：对应 OSI 网络层，核心协议 IP，单位 IP 数据报；无连接不可靠，负责路由
3. **传输层**：TCP、UDP，和 OSI 传输层功能一致
4. **应用层**：合并 OSI 会话、表示、应用三层，包含所有应用协议

## 三、OSI vs TCP/IP 对比

### 相同点

1. 分层架构、独立协议栈
2. 异构网络互联
3. 层次功能大体相似

### 核心区别

1. 层数：OSI7 层 / TCP/IP4 层
2. 设计顺序：OSI 先模型后协议；TCP/IP 先协议后模型
3. 网络层：OSI 支持无连接 + 面向连接；TCP/IP 仅无连接
4. 传输层：OSI 两种模式都支持；TCP/IP 仅 TCP 面向连接、UDP 无连接
5. 市场：OSI 理论完善但无商用；TCP/IP 互联网通用标准

## 四、五层折中体系（教材通用）

合并 OSI+TCP/IP 优点：物理层、数据链路层、网络层、传输层、应用层

## 五、数据封装核心流程

发送端自上而下：上层数据 + 本层首部 (PCI) → 本层 PDU，作为下层 SDU 层层封装

接收端自下而上：逐层剥离首部，解封装向上递交

公式：`n-SDU + n-PCI = n-PDU = (n-1)-SDU`
