📊数字数据 → 数字信号：5 种基带编码（必考！）

▔╲▁╱▔╲▁╱
RZ 归零编码
✓ 自同步效率低
每个码元中间归零；高电平=1，低电平=0。自带跳变沿同步，但归零占额外带宽
▔▔▔▁▁▔▔▔
NRZ 非归零编码
✗ 无自同步效率最高
全程维持电平不归零。带宽利用率最高，但连续0/1会丢失时钟
━┃━┃━━┃━
NRZI 反向非归零
✓ 自同步差分判断
跳变=0，不变=1；看相对变化。USB 2.0 使用 NRZI
▔╲▁╱▔╲▁╱
曼彻斯特编码
✓ 自同步数据+时钟
每个码元中间必跳变；下降沿=1，上升沿=0。传统以太网标准
┃╱┃╲┃┃╱┃
差分曼彻斯特
✓ 自同步差分+抗干扰
中间也必跳变；起始跳变=0，不变=1。不怕线路极性颠倒
编码自同步特点应用
RZ✅中间归零，带宽效率低—
NRZ❌ 唯一没有的带宽利用率最高需单独时钟线
NRZI✅差分，跳变=0/不变=1USB 2.0
曼彻斯特✅中间必跳，下降1/上升0传统以太网
差分曼彻斯特✅起始跳变=0/不变=1；抗极性颠倒宽带高速网
🧠 区分记忆  曼彻斯特看跳变方向（下降/上升） |  差分曼彻斯特看开头有没有跳变

📻数字数据 → 模拟信号：载波调制（改变正弦波三要素）

载波三要素：振幅 · 频率 · 相位

ASK 幅移键控（调幅）
改变：振幅  |  有振幅=1，无振幅=0
✅ 实现简单  |  ❌ 抗干扰能力差
FSK 频移键控（调频）
改变：频率  |  f₁=1，f₂=0
✅ 易实现  |  ✅ 抗干扰强，应用广泛
PSK / DPSK 相移键控（调相）
改变：相位
绝对PSK：固定相位代表数值（→相位反转问题） |  DPSK：差分判断，对比前码元相位，抗干扰更好
QAM 正交幅度调制（混合调制）
改变：振幅 + 相位同时调制
公式：R = B·log₂(mn)  |  B=波特率，m=相位数，n=振幅数
相同带宽承载更多比特，频带利用率最高

📞模拟数据 → 模拟信号

应用：老式电话机，配合 FDM 频分复用，多路低频语音调制到高频载波，共用一条信道传输。

⭐必背结论 & 易混辨析

✅ 具备自同步的编码

RZ ✓ 曼彻斯特 ✓ 差分曼彻斯特 ✓ NRZI ✓

❌ 无自同步

NRZ（非归零编码）— 唯一没有的

🔌 经典应用

以太网 → 曼彻斯特 USB 2.0 → NRZI

🔒 差分编码优势

NRZI、差分曼彻斯特、DPSK — 不怕线路极性颠倒，双绞线正负极接反也能正确解码

📊 调制性能排序

抗干扰：ASK 最差 → FSK 强
频带利用率：QAM 最高（同时调幅+调相）

⚡ 核心区分

编码 → 数字信号（高低电平、基带、网线传输）
调制 → 模拟载波信号（正弦波、无线/电话线远距离）
