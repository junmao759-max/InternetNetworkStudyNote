⚡ 速率换算

比特率 = 波特率 × log₂k
(k = 码元进制数)
📝 实例：4 进制码元（k=4），波特率 1000 Baud
→ 单码元携带 log₂4 = 2 bit
→ 比特率 = 1000 × 2 = 2000 b/s
📝 实例：8 进制码元（k=8），波特率 2000 Baud
→ 单码元携带 log₂8 = 3 bit
→ 比特率 = 2000 × 3 = 6000 b/s

🧠 小测验

❓ 一个 8 进制码元携带多少 bit 信息？
✅ 3 bit
公式：log₂8 = 3 bit
❓ 半双工通信需要几条信道？
✅ 2 条单向信道
双方可收发但不能同时，需要两条独立信道
❓ 基带传输和宽带传输的核心区别？
✅ 基带传输：不经过调制，直接传原始信号
宽带传输：经过调制后频分复用传输
