###### 一、跨网络通信分层传输特点

主机 H1 向 H2 通信路径：`H1 → 局域网1 → R1 → 广域网 → R2 → 局域网2 → H2`

1. **主机**：具备完整五层协议（应用层→传输层→网络层→数据链路层→物理层）。
2. **路由器（R1、R2）**：只使用**下三层**（网络层、数据链路层、物理层）；路由器**没有传输层、应用层**。
3. 数据包经过每个节点时，协议栈向上、向下多次封装解封。

###### 二、数据链路层视角简化理解

研究数据链路层时，可抽象认为：数据在**各个相邻节点的数据链路层之间水平传输**。

传输链路：

`H1的数据链路层 → R1的数据链路层 → R2的数据链路层 → H2的数据链路层`

> 重点：**相邻两段链路，可以使用互不相同的数据链路层协议**。

###### 三、三组基础名词定义（必考点）

1. **链路（物理链路）**
    
    指一个节点到**相邻节点**的一段物理线路；仅仅是硬件线路，不含通信协议。一条完整通信路径由多条链路串联组成。
    
2. **数据链路（逻辑链路）**
    
    在物理链路上，增加实现控制传输的**硬件 + 通信协议**，构成数据链路。
    
    简单区分：链路 = 裸线缆；数据链路 = 线缆 + 链路通信协议。
    
3. **帧**
    
    ✅ **数据链路层的协议数据单元（PDU）**
    

- 发送端：数据链路层接收网络层下发数据，封装成**帧**，发送到链路上。
- 接收端：从链路上收到帧，提取帧内承载的数据，上交网络层。

###### 四、补充背景（课本开头）

有线局域网一般使用 **CSMA/CD**；无线局域网使用 CSMA/CA（广播信道协议）。

## 考试简答要点汇总

1. 路由器只有下三层，不存在传输层与应用层。
2. 相邻链路的数据链路层协议**可以不一样**。
3. 链路 ≠ 数据链路：链路只是物理线路；数据链路 = 物理链路 + 控制协议。
4. 数据链路层传输单位：**帧**；网络层：IP 分组；传输层：报文段 / 用户数据报。
