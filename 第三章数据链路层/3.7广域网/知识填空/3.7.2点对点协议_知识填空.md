## 填空练习

1. **应用场景**：PPP 的两类应用场景是①用户主机 ↔ ____（拨号入网）；②两台网络设备直连____。
2. **PPP 三大组成部分**：①____（LCP）负责建立、配置、测试数据链路连接，协商链路参数；②____（NCP）负责为不同网络层协议配置逻辑连接，其中 IP 使用的 NCP 叫____，用来分配 IP 地址；③将 IP 数据报封装到串行链路的方法，受____限制。
3. **F 标志字段**：PPP 帧首末各 1 字节的 F 标志字段取值为____，作为帧开始/结束定界符；信息段中若出现该值需要____。
4. **A、C 字段**：地址字段 A 固定值为____，控制字段 C 固定值为____，二者均无实际意义。
5. **协议字段取值**：协议字段占____字节；`0xC021` 表示信息是____报文；`0x8021` 表示信息是____报文；`0x0021` 表示信息是____。
6. **信息部分长度**：PPP 信息部分长度为____字节，载荷____（可以/不可以）为 0 字节；FCS 校验占____字节，采用____冗余校验。
7. **透明传输**：异步传输采用____填充，转义字符为____；同步传输采用____填充。
8. **与以太网区别**：PPP 是点对点链路，____（有/没有）CSMA/CD，____（有/没有）最短帧限制；PPP 面向____，帧长度一定是整数个字节；以太网数据部分长度为____字节。
9. **状态流转**：拨号接入 ISP 的流程为：链路静止 → 物理层连接建立 → 链路建立状态（交互____分组，协商链路参数）→ 鉴别状态（____认证）→ 网络层协议状态（交互____，ISP 分配临时 IP 地址）→ ____状态，可传输 IP 报文。
10. **LCP 失败处理**：链路建立阶段 LCP 协商失败会返回____；鉴别失败则链路____。
11. **通信结束**：通信结束后由____释放链路，回到链路静止状态。
12. **四大特点（1）**：PPP 只做 CRC 差错检测，____（有/没有）序号、____（有/没有）确认重传机制，数据链路层提供____（可靠/不可靠）服务；只检错，不纠错。
13. **四大特点（2）**：PPP 仅支持____点对点链路，不支持____线路；两端可运行不同网络层协议共用同一条链路；面向字节，帧长为____字节。
14. **易错辨析**：LCP 管____层面（还没 IP）；NCP 管____参数（IP 地址）；LCP/NCP 本身封装在 PPP 帧的____部分，靠____字段区分类型。
15. **MAC 地址**：PPP____（有/没有）MAC 地址概念；地址字段 0xFF 是____，不用于寻址。
