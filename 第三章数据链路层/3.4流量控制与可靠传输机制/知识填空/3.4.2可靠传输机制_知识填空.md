## 填空练习

1. **可靠传输定义**：可靠传输指发送的数据全部 ____ 交付接收方；依靠 ____ 和 ____ 实现。
2. **SW 窗口与编号**：停止-等待协议中 WT = ____、WR = ____；序号只用 ____ 比特，按 0/1 交替编号。
3. **SW 数据丢失**：数据帧出错/丢失时，接收方 ____；发送方依靠 ____ 重传。
4. **SW 的 ACK 丢失**：ACK 确认帧丢失时，接收方收到重复数据帧后直接 ____，并重新发送 ____。
5. **GBN 累积确认**：GBN 中 ACK n 代表：____ 号帧全部正确收到，期望接收 ____ 号帧。
6. **GBN 核心缺陷**：GBN 接收方只能 ____ 接收帧（因为接收窗口只能为 ____）。
7. **GBN 重传范围**：一旦某一帧出错/丢失，该帧以及 ____ 所有已经发送的帧全部需要重传。
8. **GBN 适用场景**：适用于信道误码率较 ____ 的环境；差错多时大量不必要重传，效率暴跌。
9. **SR 优化目标**：选择重传 SR 只重传 ____ 的帧，不重传后续正确到达的帧。
10. **SR 接收能力**：SR 接收方可以缓存 ____、但序号落在接收窗口内的正确帧；等到缺失帧修复后一次性按序上交上层。
11. **SR 否定确认**：检测到帧出错时，接收方发送 ____（NAK），要求发送方单独重传指定帧。
12. **SR 窗口约束**：SR 中 WT ≤ ____，防止序号重叠无法区分新旧帧。
13. **SR 优缺点**：SR 信道利用率最 ____；缺点是接收方需要缓存乱序帧，____ 复杂。
14. **信道利用率定义**：信道利用率 = 发送周期内 ____ 时长 / ____ 总时长。
15. **SW 利用率公式**：停止-等待协议利用率 U = ____（用 TD、RTT、TA 表示）。
16. **连续 ARQ 发不完**：当 n·TD < TD + RTT + TA 时，U = ____。
17. **连续 ARQ 填满**：当 n·TD ≥ TD + RTT + TA 时，窗口足够大，信道利用率 U = ____。
18. **平均速率关系**：信道平均传输速率 = ____ × ____。
19. **GBN vs SR 窗口**：GBN 接收窗口 = ____，只能顺序收；SR 接收窗口 ____ 1，可以缓存乱序帧。
20. **最大窗口上限**：n 比特编号时，GBN 最大发送窗口为 ____；SR 最大窗口上限为 ____。
21. **概念区分**：流量控制控制 ____；可靠传输依靠 ____ 保证数据不错不漏；链路层滑动窗口大小 ____，TCP 接收方可以动态调整。
