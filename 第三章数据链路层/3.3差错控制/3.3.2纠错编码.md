###### 1. 码距（海明距离）

- 码距：两个码字做异或，结果中`1`的个数；**编码集的码距 = 集合内所有码字码距的最小值**。
- 核心定理（必考）
    
    1. 检测出**d 位错误**：要求码距 \(l \ge d+1\)
    2. 纠正**c 位错误**：要求码距 \(l \ge 2c+1\)
    

###### 2. 海明码

1. 作用：**可以发现错误、定位 1 位错并自动纠正**。
2. 条件公式：设信息位 n 位，校验位 k 位

\(\boldsymbol{2^k \ge n + k + 1}\)

3. 编码规则

① 校验位固定放在 \(2^{0},2^{1},2^{2}…\) 下标位置（1、2、4、8……）

② 信息位填充剩下位置

③ 每一个信息位，由**下标包含该 2 的幂次**的校验位分组监督

④ 每一组内所有比特异或，得到对应校验位的值

4. 检错纠错原理

接收端分组奇偶校验，得到一组校验因子；

若全部为 0：无错；非 0 的二进制数值 = **出错比特位置**，比特取反即可完成纠错。

###### 易混考点总结（背诵）

1. 奇偶校验码：检奇数错，**不能纠错**
2. CRC 循环冗余码：强检错能力；链路层只检错、不纠错
3. 海明码：可**检测并纠正 1 位错误**；依靠码距理论
4. ARQ 依靠检错编码，出错重传；FEC 依靠纠错编码，本地修复
