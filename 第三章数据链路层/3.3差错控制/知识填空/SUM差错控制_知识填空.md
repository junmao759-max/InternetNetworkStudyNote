## 填空练习

1. **最基础差错**：传输差错最基础类型是 ____，即传输中比特 0↔1 发生 ____。
2. **ARQ**：ARQ 中文名为 ____，接收方检测出错后通知发送方 ____；它只能 ____，不能 ____。
3. **FEC**：FEC 中文名为 ____，接收方检测出差错后可以 ____、直接纠正，____（需要/无需）重传。
4. **编码分类**：差错控制编码分为 ____ 和 ____ 两类。
5. **奇偶校验**：奇校验要求码字中 `1` 总数为 ____，偶校验为 ____；它仅能检测 ____ 位出错，____（能/不能）定位错误位置。
6. **CRC 多项式**：收发双方预先协商生成多项式 G(x)，其二进制串最低位一定是 ____。
7. **CRC 收发**：发送端在信息比特后附加 ____ 位 FCS；接收端用相同多项式除收到的帧，余数 = ____ 即无差错。
8. **CRC 运算**：CRC 采用 ____ 除法（本质异或，无进位无借位）；数据链路层只用它做 ____，≤ ____ 位的突发差错可 100% 检出。
9. **码距**：编码集的码距 = 集合内所有码字码距的 ____ 值；检 d 位错要求码距 ≥ ____，纠 c 位错要求码距 ≥ ____。
10. **海明码条件**：信息位 n、校验位 k，须满足 ____；校验位放在下标为 ____ 的位置。
11. **海明码能力**：海明码可发现错误、定位 ____ 位错并自动纠正；接收端校验因子非 0 的二进制数值就是 ____。
12. **编码对比**：奇偶校验不能纠错；CRC 链路层只检错不纠错；海明码依靠 ____ 理论可纠正 1 位错。
