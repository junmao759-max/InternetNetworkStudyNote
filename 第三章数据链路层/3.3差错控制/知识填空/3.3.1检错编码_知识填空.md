## 填空练习

1. **奇偶校验分类**：奇偶校验码分为 ____ 和 ____，是最简单的检错手段。
2. **奇校验定义**：奇校验要求整个码字中 `1` 的总数为 ____。
3. **偶校验定义**：偶校验要求整个码字中 `1` 的总数为 ____。
4. **奇偶校验局限**：仅能检测 ____ 个位出错；无法检测 ____ 位出错；____（能/不能）定位错误比特位置。
5. **CRC 核心思想**：收发双方预先协商生成多项式 G(x)，其二进制比特串最低位一定是 ____。
6. **CRC 发送端**：信息比特后附加 ____ 位冗余码（即 FCS 帧检验序列）。
7. **CRC 接收端**：用相同多项式去除收到的完整帧；余数 = ____ 代表无差错。
8. **CRC 运算本质**：CRC 计算采用 ____ 除法，本质是 ____ 运算，无进位无借位。
9. **CRC 步骤①**：设 G(x) 阶数为 r，则原始数据末尾补 ____ 个 0。
10. **CRC 步骤③**：得到 r 位余数后，____（如何处理），就是最终发送帧。
11. **CRC 纠错定位**：CRC ____（具备/不具备）纠错能力，但数据链路层只使用它做 ____，检测出错直接 ____ 帧。
12. **CRC 检错结论**：凡是少于等于 ____ 位的突发差错可以 100% 检出；它不能做到绝对无差错，只是漏检概率 ____。
