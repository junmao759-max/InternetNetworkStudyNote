###### 奇偶检验码

- 分为**奇校验、偶校验**，最简单的检错手段。
    
    - 奇校验：整个码字中`1`总数为**奇数**
    - 偶校验：整个码字中`1`总数为**偶数**
    
- 局限：**仅能检测奇数个位出错；无法检测偶数位出错；不能定位错误比特位置**。

###### 2. CRC 循环冗余码（数据链路层高频考点）

1. 核心思想
    
    - 收发双方预先协商生成多项式 \(G(x)\)（二进制比特串，最低位一定是 1）。
    - 发送端：信息比特后附加**r 位冗余码（FCS 帧检验序列）**；
    - 接收端：用相同多项式去除收到的完整帧；余数 = 0 代表无差错。
    
2. CRC 计算步骤（模 2 除法，异或运算，无进位无借位）
    
    ① 设 G (x 阶数为 r，原始数据末尾补`r个0`
    
    ② 使用模 2 除法，除以 G (x) 对应二进制串
    
    ③ 得到 r 位余数，**替换末尾 r 个 0，就是最终发送帧**
3. 重要结论
    
    - CRC**具备纠错能力，但数据链路层只使用它做检错**，检测出错直接丢弃帧。
    - CRC 可以做到：**凡是少于等于 r 位的突发差错 100% 检出**；不能做到绝对无差错，只是漏检概率极低。
