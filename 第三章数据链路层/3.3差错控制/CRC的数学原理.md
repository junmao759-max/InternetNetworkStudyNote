1.我们设T(x)为正确的数据串，T'(x)为最终接收到的数据串，E(x)为错误二进制（这里说的错误二进制指的是错误位数，比如相对于原始数据串的第二三位有错那么数据串就为1100）G(x)为协商好的生成多项式。

2.T(x)因为为正确的数据串，所以T(x) mod G(x) = 0

3.此时T'(x) = T(x) + E(x)
T'(x) mod G(x) = ( T(x) + E(x) ) mod G(x) = T(x) mod G(x) + E(x) mod G(x) 又因为2 最终得到 T'(x) = E(x) mod G(x)

因此它的两个性质在这里就可以解释了
1.首先是关于它的对于出错位数小于或等于r的情况下一定能检测出错误。因为这种情况下E（x）的错误部分一定不能被整除 即使它的次数很高也无法被整除。本质是单看错误部分一定比G(x)小。比如1000 不能被1011整除 那么即使变成1000000也不能被整除。
2.对于奇数位错误一定能检出是因为生成多项式往往携带了(x+1)这一项，而如果你的生成多项式携带这一项的话，那么对于奇数个1的E(x)那么就一定不能整除。
