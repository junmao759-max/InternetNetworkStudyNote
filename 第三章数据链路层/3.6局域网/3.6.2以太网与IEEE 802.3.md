###### 1. 以太网标准演进

1. 最早版本：DIX Ethernet V1（DEC、Intel、Xerox）
2. DIX Ethernet V2（以太网 V2），世界第一个局域网产品规约
3. IEEE 802.3：IEEE 制定局域网标准

> 考点：两者差别很小，日常所说**802.3 局域网 ≈ 以太网**

###### 2. 以太网通信特点（无连接工作方式）

1. **无连接**：不对发送帧编号，**不要求接收方确认**，属于不可靠交付
2. 差错纠正交由上层（传输层）完成
3. 信号编码：**曼彻斯特编码**；码元中间电压跳变，接收端从中提取同步时钟

###### 3. 传统 10M 以太网标准（10BASE-x）

表格

|标准|介质|拓扑|最大段长|
|---|---|---|---|
|10BASE5|粗同轴电缆|总线|500m|
|10BASE2|细同轴电缆|总线|185m|
|10BASE-T|非屏蔽双绞线|星形|100m|
|10BASE-F|光纤|点对点|2000m|

> 命名规则：
> 
> 10=10Mb/s；**Base = 基带传输**；T = 双绞线，F = 光纤，数字代表最大段长

###### 4. 网卡（网络适配器 NIC）功能

网卡工作在**数据链路层**

功能清单：

1. 串 / 并行数据转换
2. 帧封装、解封
3. 介质访问控制（CSMA/CD）
4. 编码、解码
5. 数据缓存
6. 收到正确帧后通过中断通知 CPU

###### 5. MAC 地址（物理地址）

1. 长度：**48 位（6 字节）**，固化在网卡 ROM，全球唯一
2. 结构：前 24 位 = **厂商 OUI 代码**；后 24 位 = 厂商分配序列号
3. 三种帧类型（目标 MAC）
    
    - **单播帧**：一对一，目标 MAC 唯一主机
    - **广播帧**：一对全体，目的 MAC 全 1（FF-FF-FF-FF-FF-FF）
    - **多播帧**：一对一组，目标 MAC 最高位 = 1
    

###### 6. 以太网 V2 MAC 帧格式（重中之重）

**【前导码（物理层，不属于 MAC 帧）】**

8 字节：7 字节**前同步码 + 1 字节帧开始定界符**，用于比特同步

**MAC 帧头部 + 尾部（18 字节）**

1. 目的地址：6B 目标 MAC
2. 源地址：6B 发送方 MAC
3. 类型：2B 上层协议类型（0x0800 代表 IP）
4. 数据：**46 ~ 1500B**（载荷）
5. FCS 校验：4B CRC32
    
    ✅ 最短帧长：`18 + 46 = 64字节`
    
    ✅ 最长帧长：`18 + 1500 = 1518字节`

> 关键考点：

6. 不足 46 字节时，MAC 层**填充字段**保证帧≥64 字节（CSMA/CD 冲突检测要求）
7. FCS 校验范围：目的 MAC ~ 数据段，**不校验前导码**
8. IEEE802.3 和以太网 V2 区别：
    
    802.3 使用**长度字段**替代 V2 的类型字段；数值≤1500 代表长度；>1500 代表类型

###### 4. 高速以太网（速率≥100Mb/s）

###### （1）100BASE-T（快速以太网 100Mbps）

- 介质：双绞线；星形拓扑
- 半双工：**使用 CSMA/CD**
- 全双工：无信道竞争，**不使用 CSMA/CD**
- 网段最大长度：100m
- MAC 帧格式、最小 / 最大帧长**保持不变**

###### （2）吉比特以太网（1Gb/s）

- 介质：双绞线 / 光纤
- 半双工：CSMA/CD；全双工无冲突，不用 CSMA/CD
- **向下兼容 10M/100M 以太网**
- 帧格式、64B 最小帧、1518B 最大帧不变

###### （3）10 吉比特以太网（10Gb/s）

1. **只支持全双工模式**
2. 不存在信道竞争 → **完全不需要 CSMA/CD 协议**
3. 保留原有帧格式、长短限制，完美向下兼容
4. 传输介质：光纤 / 双绞线

> 通用规律总结

- 半双工共享信道：必须 **CSMA/CD**
- 交换机全双工点对点链路：无冲突，**不需要 CSMA/CD**

###### 3.6.3 IEEE 802.11 无线局域网（Wi-Fi）

###### 1. 两大类 WLAN

1. **有固定基础设施**：存在 AP 接入点（最常用 Wi-Fi）
2. 无固定基础设施：自组织网络（Ad Hoc）

###### 2. 基础概念

- AP：无线接入点（路由器无线模块）
- BSS（基本服务集）：一个 AP + 下属所有移动站点（最小单元）
- BSA：基本服务区，覆盖范围一般≤100m
- SSID：无线网络名称（≤32 字节）
- MAC 层协议：**CSMA/CA（冲突避免）**（有线以太网是 CSMA/CD 冲突检测）

###### 易混对比 简答题考点

- 有线以太网（802.3）：CSMA/CD 冲突检测
- 无线局域网（802.11）：CSMA/CA 冲突避免

###### 高频简答题汇总

1. 以太网最短 64 字节怎么得来？
    
    答：MAC 首部 18 字节，数据段最小 46 字节，18+46=64 字节；为满足 CSMA/CD 冲突检测需求。
2. 全双工以太网为什么不需要 CSMA/CD？
    
    答：收发通道独立，点对点链路，不会发生同时发送冲突。
3. MAC 地址三种帧区分：单播、广播、多播。
4. 前导码属于物理层，不属于 MAC 帧本身。
