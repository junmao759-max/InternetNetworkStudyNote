###### 一、VLAN 产生背景

原始以太网是**单一广播域**。主机数量大时，ARP、DHCP 等广播报文泛滥，带宽占用大、安全性差。

**VLAN（Virtual LAN，虚拟局域网）**：把一个物理局域网，**逻辑分割成多个广播域**。

1. 同一 VLAN 内主机：可以直接互通（二层转发）
2. **不同 VLAN 主机：二层不能直接通信，必须经过路由器 / 三层交换机**

###### 二、三种 VLAN 划分方式（考点）

###### 1. **基于接口（端口划分）【最常用】**
    
    交换机端口绑定 VLAN。主机更换交换机端口，可能划入新 VLAN。简单高效。
2. **基于 MAC 地址划分**
    
    MAC 地址和 VLAN 绑定。主机换接口，VLAN 不变。
3. **基于 IP 地址（网络层）**
    
    依据 IP / 子网划分，可以跨路由器部署 VLAN。

###### 三、802.1Q（VLAN 标签技术，重中之重）

###### 1. 帧结构

标准以太网帧基础上，**源 MAC 地址 和 类型字段之间插入 4 字节 VLAN 标签**，构成 **802.1Q 帧**。

> 原始以太网最小帧长 64 字节；插入 4 字节标签后最小长度变为 **68 字节**
> 
> 最大帧长：1518 → **1522 字节**

###### 2. VLAN 标签 4 字节组成

- **前 2 字节：TPID = `0x8100`**
    
    标志：这是携带 VLAN 标签的 802.1Q 帧
- **后 2 字节：TCI**
    
    - 高 4 位：优先级（一般不考）
    - **低 12 位：VID（VLAN 标识符）**
        
        \(12\mathrm{bit} \Rightarrow 2^{12}=4096\) 个 VLAN。
        
        VID=0、4095 保留，可用范围：**1~4094**
    

> 重要：插入标签后，**FCS 校验必须重新计算**！

###### 四、两种链路类型

1. **接入链路 Access Link**
    
    交换机 ↔ PC / 终端
    
    传输**标准以太网帧（不带 VLAN 标签）**
    
    PC 主机**不知道 VID，只有交换机维护 VLAN 信息**。
    
    交换机收到主机帧，**打上 VID 标签**；发往主机时**剥离标签**。
    
2. **干线链路（汇聚链路 Trunk）**
    
    交换机 ↔ 交换机
    
    链路上传输 **带标签的 802.1Q 帧**
    
    依靠 VID 区分不同 VLAN 流量，实现 VLAN 跨多台交换机。
    

###### 五、转发核心规则（大题常考）

1. PC 发送普通无标签帧进入交换机 Access 口 → **交换机打上对应 VID 标签**
2. 跨交换机 Trunk 链路：携带 802.1Q 标签传输
3. 帧到达目标交换机 Access 口：**剥离 VLAN 标签**，还原普通以太网帧发给终端
4. **同 VLAN：二层交换机直接转发；不同 VLAN：二层隔离，必须三层设备（路由器 / 三层交换）路由互通**

举例：VLAN10 和 VLAN20 主机即使连同一台交换机，也无法二层通信。

###### 六、高频概念辨析

1. VLAN **不是新型局域网**，是交换机提供的**逻辑划分服务**。
2. VLAN 隔离的是**广播域**，冲突域不受 VLAN 影响。
3. 主机本身感知不到 VLAN 标签，打标签、去标签全部由**交换机硬件完成**。
4. Trunk 链路上的帧是 802.1Q 帧；终端侧永远是无标签标准以太网帧。

###### 七、简答 / 选择背诵考点汇总

1. VID 多少位？最多多少 VLAN？
    
    12 位，4096 个，可用 1~4094。
2. TPID 固定值？`0x8100`
3. 802.1Q 帧最小、最大长度：68 字节 / 1522 字节
4. 不同 VLAN 主机为什么不能二层互通？
    
    VLAN 隔离广播域，交换机不允许跨 VLAN 二层转发，需要三层路由。
5. Access 链路和 Trunk 链路区别：
    
    Access：无标签，连接终端；Trunk：带 802.1Q 标签，交换机之间互联。
